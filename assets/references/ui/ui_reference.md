# UI/UX Reference Notes - Pet Simulator 99 Benchmark

- **Style:** Tactile 3D cartoon with chunky bottom bevels and bouncy click animations.
- **HUD:** Top-right coin bar, equipped pets badge, left-docked feature buttons.
- **Palette:** Soft pastel lavender (#DED2F9), mint green (#A8E6CF), sky blue (#A0D2EB), and deep violet (#2D253F) outlines.
- **Responsiveness:** Standard AnchorPoint 0.5 centered popups with UIScale constraints for mobile compatibility.
